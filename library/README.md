# Document library

120 documents. Generated by `npm run build:library`; edit the source in `src/library`, not these files.

Every document is a draft. Every blank reads "[Fill in: …]". Items marked Needs review are drafting outlines for a qualified person, not legal advice. Statutes named are pointers for that reviewer.

Save into the warehouse with `npm run seed:library` (idempotent). Each document is then listed in the Library, downloadable as Word, Excel, HTML, Markdown, JSON or CSV, and editable.
