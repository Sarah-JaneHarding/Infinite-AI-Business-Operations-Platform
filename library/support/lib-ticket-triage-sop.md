1. Log the ticket with school, contact and time.
2. Check for personal information in the message. Do not copy it into notes or tools.
3. Set severity using the table in the SLA.
4. Assign an owner.
5. Reply to confirm receipt.
6. Resolve or escalate (lib-escalation-matrix).
7. Close with the customer’s confirmation.

> **WARN** A ticket that mentions a possible data breach goes to the breach SOP immediately.
